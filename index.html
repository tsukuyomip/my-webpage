Projects

🎛️ Mixer

複数の音源・動画をタイムライン上で整列し、mute / solo / SE を切り替えながらプレビューできる Web アプリ。

🎚️ Make Medley

曲を読み込むと BPM と調を自動解析し、波形に拍を可視化。拍を揃えてクロスフェードでメドレー化できる Web アプリ。全処理は端末内で完結。

📦 Media Vault

画像・動画をブラウザ内に保存し、文字認識（OCR）と文字起こしでテキスト検索できる Web アプリ。データは端末から出ません。

🎴 学マス サポカ棚卸し

所持サポートカード一覧のスクショを画像認識し、wiki の名称でカード名・Lv・凸数を一覧化して CSV/JSON 出力できる Web アプリ。

🚄 おえかきトレイン

指で線路を描くと 3D の新幹線・電車・SL が走り出す箱庭アプリ。交差点は自動でポイントになり、線路のまわりには駅や街が自動で建つ。

🎰 DOPAMINE CALC

無駄にド派手な電卓。「=」を押すたびレアリティ抽選、SSR以上で「プチュン」。DPを貯めてスキンガチャも回せる。

🎲 DOPAMINE SLOT

ドーパミンドバドバのスロット/サイコロ。リーチ演出、ゾロ目でJACKPOT。結果は演出ごとURLで完全再現共有できる。

🏠 TMMN HOUSE

中庭のあるビルトインガレージハウスの間取りビューア。部屋をタップすると面積・仕上げ・内装カットが開き、3Dモードでは一人称で家の中を歩ける。面積も3Dも同じ図形から生成され、図面と食い違わない。

🎮 toio コントロールパネル

ブラウザから toio コアキューブを Bluetooth 接続して操作する開発者向けパネル。モーター・ランプ・サウンド・各種センサー・設定・生コマンドまで BLE 仕様の機能をひととおり網羅。

🕹️ toio リンクコントロール

toio コアキューブ 2 台を接続し、片方を手に持つコントローラにして、もう片方を走らせる。傾けた角度で無段階に前進・後退、回した向きに追従。実機と連動する 3D 姿勢・水準器・走行の軌跡を並べて見られる。
