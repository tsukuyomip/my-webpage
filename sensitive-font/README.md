# ✨ 透過文字ジェネレータ

同人誌のコマに重ねる「あえぎ文字 / 効果音文字」を作るためのツール。
テキストを打ち込み、フォントと装飾を選んで **背景透過 PNG** としてダウンロードできます。

入力したテキストも、作った画像も、読み込んだフォントもどこにも送信されません。
すべてブラウザ内（Canvas 2D）で処理されます。

## できること

- **多重縁取り** — 最大 5 層。色と太さを層ごとに指定でき、白フチ + 黒フチのような
  二重・三重の縁取りが作れます。
- **塗り** — 単色 / グラデーション（2〜3 色・角度指定）/ 縞。
- **影** — ぼかし影と、ずらしたベタ影の 2 種類。
- **縦書き** — `ー` `〜` `（）` などは 90° 回転、小書きかな・句読点は右上に寄せます。
- **濁点合成** — `イ゛グ゛ッ` のように、本来は濁点が付かない文字にも結合濁点（U+3099）を
  まとめて付けられます。
- **ゆらぎ** — 文字ごとにサイズ・傾き・上下位置をランダム（seed 固定可）またはサイン波で
  揺らします。傾き・回転・アーチ配置も。
- **フォント** — Google Fonts の日本語 OFL 書体を 27 種類。加えて **手持ちのフォント
  ファイル（ttf / otf / woff / woff2）を読み込んで使えます**。
- **書き出し** — 余白を自動トリムした透過 PNG を 1x / 2x / 4x で保存、クリップボードへコピー。
  設定は localStorage に保存され、`#c=...` 付き URL で共有・復元できます。
- **プレビュー** — 市松 / 白 / 黒 / 任意の画像を背景に敷いて、実際に貼ったときの見え方を確認。

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # tsc 型チェック + vite ビルド
```

GitHub Pages では `/my-webpage/sensitive-font/` 以下に配信されます
（`vite.config.ts` の `base` を参照）。

## 実装メモ

- **描画経路は 1 本**。プレビューも書き出しも `src/render/draw.ts` の `renderText()` を
  倍率違いで呼ぶだけにして、見た目と出力がズレないようにしています。
- **フォントのロード待ちは必須**。Canvas は未ロードのフォントを黙って代替書体で描くため、
  描画前に `document.fonts.load()` を待ちます。Google Fonts は `unicode-range` で
  分割配信されるので、**描く文字を渡さないと必要なサブセットが落ちてきません**。
  ただし待ちっぱなしで固まらないよう、プレビューは 1.5 秒で打ち切って代替書体で先に表示し、
  フォントが遅れて届いたら `document.fonts` の `loadingdone` で描き直します。
- **多重縁取り**は `strokeText` の線幅が字面の内外に半分ずつ乗る性質を使い、
  外側の層から順に `lineWidth = 2 × 外周までの累計幅` で描いて内側で上書きしています。
  1 文字ずつ全層を描くと隣の文字の縁が上に乗るため、**層ごとに全文字を描く**順序です。
- **グラデーション**は塗る瞬間の座標系で解釈されるため、文字ごとに transform をかけた
  状態で塗ると 1 文字ずつグラデが繰り返されます。文字の形のマスクを別キャンバスに作り、
  そこへ矩形グラデを `source-in` で流し込んでいます。
- **縦書き**は Canvas に機能がないので 1 文字ずつ配置しています。回転対象の文字・小書きかな・
  句読点はテーブル + オフセットで処理。OpenType の `vert` 特性は Canvas から使えません。

## 限界

- Google Fonts 由来の書体は閲覧時に外部リクエストが発生します（テキストは送信されません）。
  完全にオフラインで使いたい場合は手持ちフォントの読み込みを使ってください。
- 手持ちフォントで作った画像を配布してよいかは、そのフォントのライセンス次第です。
- 濁点合成や小書きかなの位置は書体依存で、ズレることがあります。
- 保存ファイル名は、日本語だけのテキストだと環境によって拡張子ごと捨てられてしまうため、
  ASCII に落とせないときは `moji-YYYYMMDD-hhmmss.png` になります。
- 巨大な文字数 × 4x 出力では Canvas の最大サイズ（概ね 16384px）に当たります。
  その場合は自動で倍率を下げ、書き出し後にその旨を表示します。
