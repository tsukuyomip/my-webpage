設定

旋回の速さは「離れているほど速く、近づくほど緩やか」に決まります。全速になる角度まで離れたら 最大旋回速度、不感帯を出たところが最低旋回速度で、その間を減速カーブがつなぎます （カーブを上げるほど手前で減速します）。 行ったり来たりして揺れるときは、最大旋回速度を下げる・減速カーブを上げる・旋回のなましを長くする、 の順に試すのが効きます。逆に反応が鈍いときは全速になる角度を小さくしてください。 向きが逆に回ってしまう場合は、キューブの IMU の符号が想定と逆なので「ヨーを反転」を試してください。

キューブのピッチは上向きが正、下向きが負です。前に傾ける（下向き）と前進、 後ろに傾ける（上向き）と後退します。逆のほうが好みなら「前後を反転」を入れてください。 反応カーブを上げるほど、中央付近がゆるやかになって微速が出しやすくなります。 「基準にピッチも含める」を切ると、水平（ピッチ 0°）が常に停止位置になります。

送信間隔を詰めすぎると BLE が詰まって、かえって反応が悪くなります。60ms 前後が目安です。 キーボードの Space / Esc でいつでも停止できます。

姿勢角検出は BLE プロトコルバージョン 2.3.0 以降のファームウェアが必要です。 古いキューブでは設定を書いても通知が来ないので、上のステータスでバージョンを確認してください。

推測航法の精度を上げるには、実際に 1m 走らせて推定座標と見比べ、速度係数を合わせます。 その場で 360° 回して角度が合わない場合は輪距を調整します（向きに位置IDや姿勢角を使っている場合は関係ありません）。

3D モデルが実機と逆に傾く場合は、上の反転で合わせてください（IMU の符号の取り方はキューブ側の仕様に 明記がないため、実機を見ながら決めるのが確実です）。ヨーの向きは「追従」タブの反転設定に従います。

設定はこの端末のブラウザに保存されます。

通信ログ送受信のバイト列

走行中は毎秒十数回のモーター指示が出るので、送信は既定で伏せています。

Web Bluetooth を直接使っています。HTTPS または localhost、かつ Chrome / Edge 系ブラウザが必要です。 バイト列は toio 公式 BLE 通信仕様 に準拠。 1 台だけを細かく操作したいときは コントロールパネル をどうぞ。
