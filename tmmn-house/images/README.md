# 内装写真の置き方

このフォルダに **視点ID と同じ名前** で画像を置くだけで、アプリのプレースホルダが
その写真に差し替わります。コードもデータも編集する必要はありません。

```
tmmn-house/images/<視点ID>.jpg
```

拡張子は `.jpg` → `.jpeg` → `.png` → `.webp` の順に探し、最初に見つかったものを使います。
置いていない視点は、その部屋の仕上げ材の色から作ったプレースホルダのままになります。

> ブラウザの開発者コンソールに 404 が出ますが、これは「まだ画像を置いていない視点を
> 探しにいった」ログなので、動作上の問題はありません。

## 推奨する画像の仕様

- **縦横比**: 4:3（枠が 4:3 で、`object-fit: cover` で切り取られます）
- **長辺**: 1600px 程度。GitHub Pages に載るので、あまり大きくしすぎないこと
- **形式**: `.jpg`（写真）または `.webp`

## 視点を増やしたい・減らしたいとき

`../data/house.js` の該当する室の `views` を編集してください。

```js
views: [
  { id: 'gym', label: '入口からミラー壁側を見る', at: [7.1, 9.4], dir: 60, ref: 4 },
]
```

| フィールド | 意味 |
|---|---|
| `id` | 視点ID。**そのまま画像ファイル名になります** |
| `label` | 画面に出る説明 |
| `at` | 立ち位置 `[x, y]`（メートル。建物北西角が原点） |
| `dir` | 視線の方位（度）。`0`=北 `90`=東 `180`=南 `270`=西 |
| `ref` | 参考写真の通し番号（任意。キャプションに出るだけ） |

`at` がその部屋の外に出ていると、アプリの【検算】タブが警告します。

## 権利について

参考写真は建築事務所の作品写真と思われるものを含みます。GitHub Pages は公開サイトなので、
写真をここに置いて公開する場合は、権利の扱いをご確認ください。
