# TMMN HOUSE

約52坪・中庭のあるビルトインガレージハウスの、**間取り図と3Dウォークスルーで内装を見るビューア**。

- **平面図モード** — 部屋をタップすると、面積・仕上げ・照明・特記と内装カットが開く
- **3Dウォークスルーモード** — 一人称で家の中を歩ける。階段で1F⇄2Fも行き来できる
- **俯瞰モード** — 天井を抜いて、その階だけを上から覗き込む（1F／2F 切り替え）

## 何が「矛盾なき」なのか

この手の資料は、**図面と面積表が別々に作られる**せいで数字が合わなくなります。
（実際、元にした参考プランは 1F の室面積の合計が床面積を超えていました。）

そこでこのアプリは、**面積を手で書く欄をひとつも持たない**構造にしてあります。

```
data/house.js  ──┬─→ 平面図SVG        （plan.js）
  部屋のポリゴン   ├─→ 面積・坪・畳     （geometry.js）
  だけを持つ       ├─→ 合計・延床       （geometry.js）
                  └─→ 検算             （audit.js）
```

図も数字も同じポリゴンから出るので、**両者がズレることが原理的に起きません**。
さらに【検算】タブが、毎回これを実測して確かめています。

| 検査 | 内容 |
|---|---|
| 室の合計 ＋ 吹抜・中庭 ＝ 建築面積 | 100.00㎡ にちょうど一致するか |
| 全ポリゴンが建物外形の内側 | はみ出しがないか |
| 重なりがない | 建物外形を10cm刻みの格子で実測 |
| すき間がない | 同上（被覆率100%） |
| IDが重複していない | |
| 視点マーカーが室内にある | 立ち位置が部屋の外に出ていないか |
| **上階の吹抜の真下がひとつの空間か** | 階をまたぐ検査。下に対応する空間のない“浮いた吹抜”を見つける |

3Dも同じ `house.js` から組み立てています。壁は「隣り合う格子の所属が違うところ」に立て、
開口（建具・窓）の区間だけを引き算して作るので、**図面に無い壁は3Dにも無く、その逆もありません**。
歩行の当たり判定も、壁を組み立てるときに一緒に作った格子をそのまま使っています。

さらに 3D 側では、**置いた家具そのものを当たり判定に焼き込んだうえで、
建具の前後に人が立てる空きがあるかを実測**しています
（`shell.js` の `registerFurniture` と `checkDoorClearance`）。
ベッドや棚が扉をふさいでいれば、3Dモードを開いた時点でコンソールに警告が出ます。

```
[tmmn-house] 建具の前後の空き: すべてOK
```

家具の位置を動かしたら、ブラウザのコンソールでこの行を確認してください。
棚・クローゼットは `clearSpan()` / `nearDoor()` で建具の前を自動的に避けるので、
多少ずらしても勝手に破綻しないようになっています。

## 主な数字

| 項目 | 面積 | 坪 |
|---|---:|---:|
| 建築面積（外形 10.0m × 10.0m） | 100.00㎡ | 30.25坪 |
| 1F 床面積（中庭を除く） | 90.20㎡ | 27.29坪 |
| 2F 床面積（吹抜を除く） | 82.40㎡ | 24.93坪 |
| **延床面積** | **172.60㎡** | **52.21坪** |

階高は1Fが3.0m（天井2.5m）、2Fの天井が2.7m。地盤面は1Fの床より450mm下。

吹抜・中庭は床面積に算入していません（日本の建築基準法の扱いに合わせています）。

## ファイル構成

```
tmmn-house/
├── index.html        画面の骨格
├── style.css         配色はすべてCSSカスタムプロパティ。ダークモード対応
├── app.js            状態管理・ルーティング（#/1f/doma/doma-stair）
├── data/
│   └── house.js      ★ 唯一の正。部屋のポリゴン・仕上げ・視点・設計メモ
├── src/
│   ├── geometry.js   面積・重心・単位換算
│   ├── plan.js       house.js → 平面図SVG（室名の自動フィッティング付き）
│   ├── detail.js     部屋の詳細パネル／設計メモ
│   ├── gallery.js    写真 or プレースホルダ
│   ├── audit.js      検算（階またぎを含む）
│   ├── tour.js       動線ツアー
│   └── three/        ★ 3Dウォークスルー
│       ├── scene.js      光・環境・敷地・レンダリング
│       ├── shell.js      house.js → 壁・床・天井・階段・当たり判定
│       ├── materials.js  仕上げのテクスチャを canvas で手続き的に生成
│       ├── furniture.js  室ごとの家具・什器
│       ├── tree.js       中庭のシンボルツリー
│       └── walk.js       一人称の移動・視点・階段の上り下り
├── vendor/           three.js 同梱（CDN非依存）
└── images/
    └── README.md     写真の置き方と、参考写真14枚の対応表
```

ビルド不要。素の HTML / CSS / ES モジュールだけで動きます。
three.js は `vendor/` に同梱し、`importmap` で解決しています（CDNに依存しません）。
**3Dのコードは、3Dモードを開いた時点で初めて動的importで読み込む**ので、
平面図だけ見るときに three.js（約740KB）は読み込まれません。

## 3Dの操作

3Dモードの中で「歩く」と「俯瞰」を切り替えられます。

**歩く（一人称）**

| | PC | スマホ |
|---|---|---|
| 視線 | 画面をクリック → マウス | 画面右半分をなぞる |
| 移動 | WASD ／ 矢印キー | 画面左半分をなぞる |
| 速歩き | Shift | — |
| 解除 | Esc | — |

**俯瞰（天井を抜いた見下ろし）**

| | PC | スマホ |
|---|---|---|
| 回転 | ドラッグ | なぞる |
| 拡大・縮小 | ホイール | 2本指 |
| 平行移動 | 右ドラッグ | 2本指 |

見ている階は 1F／2F タブで切り替わります。切断は「その階の天井の 0.4m 下」で、
`scene.js` の `_applyCut()` にあります。切る高さを変えたければここを直してください。

平面図の視点マーカー（▲）や、内装カットの「3Dでこの視点に立つ」から、
**写真と同じ立ち位置・同じ向き**に立てます。階段は実際に上り下りできます。

## 手を入れるとき

### 間取りを変える

`data/house.js` の `polygon` を編集します。面積・坪・畳・合計・平面図はすべて自動で追従します。
編集したら、アプリの【検算】タブが全部 OK になっていることを確認してください
（すき間や重なりができていれば、そこで分かります）。

### 3Dの見え方を変える

- 仕上げの色 … `data/house.js` の `materials`（平面図の凡例と3Dのテクスチャの両方に効きます）
- 質感（木目のピッチ、タイルの割付、粗さ）… `src/three/materials.js` の `RECIPES`
- 家具 … `src/three/furniture.js`。各室の `furnish` キーでどれを使うか決まります
- 階高・壁厚・目線の高さ … `data/house.js` の `build3d`
- 開口の高さ（窓の腰高、建具の高さ）… `data/house.js` の `openingSpecs`

### 内装写真を入れる

`images/` に視点IDと同じ名前で置くだけです。→ [images/README.md](./images/README.md)

### 仕上げ・照明・特記を書き換える

同じく `data/house.js`。仕上げ材は `materials` に定義したキーで参照します。

### 配色・トーンを変える

`style.css` の `:root` にあるカスタムプロパティ。ライト／ダークの両方が定義されています。

## ローカルで見る

ES モジュールを使っているので、`file://` で直接開くと CORS で止まります。簡易サーバー経由で開いてください。

```sh
cd my-webpage
python3 -m http.server 8000
# → http://localhost:8000/tmmn-house/
```

## 参考写真との関係

内装のイメージは提供された参考写真14枚に基づいています。写真どうし・写真と間取りの間に
あった食い違いをどう解いたかは、アプリの【設計メモ】タブに全部書いてあります
（元データは `data/house.js` の `designNotes`）。
