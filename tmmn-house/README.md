# TMMN HOUSE

約50坪・中庭のあるビルトインガレージハウスの、**間取り図から内装を見るビューア**。

平面図の部屋をタップすると、その室の面積・仕上げ・照明・特記と、内装のカットが開きます。

## 何が「矛盾なき」なのか

この手の資料は、**図面と面積表が別々に作られる**せいで数字が合わなくなります。
（実際、元にした参考プランは 1F の室面積の合計が床面積を超えていました。）

そこでこのアプリは、**面積を手で書く欄をひとつも持たない**構造にしてあります。

```
data/house.js  ──┬─→ 平面図SVG        （plan.js）
  部屋のポリゴン   ├─→ 面積・坪・畳     （geometry.js）
  だけを持つ       ├─→ 合計・延床       （geometry.js）
                  └─→ 検算             （audit.js）
```

図も数字も同じポリゴンから出るので、**両者がズレることが原理的に起きません**。
さらに【検算】タブが、毎回これを実測して確かめています。

| 検査 | 内容 |
|---|---|
| 室の合計 ＋ 吹抜・中庭 ＝ 建築面積 | 100.00㎡ にちょうど一致するか |
| 全ポリゴンが建物外形の内側 | はみ出しがないか |
| 重なりがない | 建物外形を10cm刻みの格子で実測 |
| すき間がない | 同上（被覆率100%） |
| IDが重複していない | |
| 視点マーカーが室内にある | 立ち位置が部屋の外に出ていないか |

## 主な数字

| 項目 | 面積 | 坪 |
|---|---:|---:|
| 建築面積（外形 10.0m × 10.0m） | 100.00㎡ | 30.25坪 |
| 1F 床面積（中庭を除く） | 87.40㎡ | 26.44坪 |
| 2F 床面積（吹抜を除く） | 76.24㎡ | 23.06坪 |
| **延床面積** | **163.64㎡** | **49.50坪** |

吹抜・中庭は床面積に算入していません（日本の建築基準法の扱いに合わせています）。

## ファイル構成

```
tmmn-house/
├── index.html        画面の骨格
├── style.css         配色はすべてCSSカスタムプロパティ。ダークモード対応
├── app.js            状態管理・ルーティング（#/1f/doma/doma-stair）
├── data/
│   └── house.js      ★ 唯一の正。部屋のポリゴン・仕上げ・視点・設計メモ
├── src/
│   ├── geometry.js   面積・重心・単位換算
│   ├── plan.js       house.js → 平面図SVG（室名の自動フィッティング付き）
│   ├── detail.js     部屋の詳細パネル／設計メモ
│   ├── gallery.js    写真 or プレースホルダ
│   ├── audit.js      検算
│   └── tour.js       動線ツアー
└── images/
    └── README.md     写真の置き方と、参考写真14枚の対応表
```

ビルド不要。素の HTML / CSS / ES モジュールだけで動きます。

## 手を入れるとき

### 間取りを変える

`data/house.js` の `polygon` を編集します。面積・坪・畳・合計・平面図はすべて自動で追従します。
編集したら、アプリの【検算】タブが全部 OK になっていることを確認してください
（すき間や重なりができていれば、そこで分かります）。

### 内装写真を入れる

`images/` に視点IDと同じ名前で置くだけです。→ [images/README.md](./images/README.md)

### 仕上げ・照明・特記を書き換える

同じく `data/house.js`。仕上げ材は `materials` に定義したキーで参照します。

### 配色・トーンを変える

`style.css` の `:root` にあるカスタムプロパティ。ライト／ダークの両方が定義されています。

## ローカルで見る

ES モジュールを使っているので、`file://` で直接開くと CORS で止まります。簡易サーバー経由で開いてください。

```sh
cd my-webpage
python3 -m http.server 8000
# → http://localhost:8000/tmmn-house/
```

## 参考写真との関係

内装のイメージは提供された参考写真14枚に基づいています。写真どうし・写真と間取りの間に
あった食い違いをどう解いたかは、アプリの【設計メモ】タブに全部書いてあります
（元データは `data/house.js` の `designNotes`）。
