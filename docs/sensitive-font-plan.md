# ✨ 透過文字ジェネレータ (`/sensitive-font/`) — 開発プラン

## コンテキスト（なぜ作るか）

同人誌のコマに重ねる「あえぎ文字 / 効果音文字」を作るためのツール。
テキストを打ち込み、フォントと装飾（縁取り・グラデ・影・ゆらぎ）を選んで、
**背景透過 PNG** としてダウンロードできる Web アプリ。

この用途の既存ツールは「フォントが数種類しかない」「縁取りが1本だけ」
「縦書きできない」「余白が付いたまま出力される」のどれかで詰まりがち。
そこを埋めるのが狙い。

処理はすべてブラウザ内で完結し、入力テキストも出力画像もサーバへ送らない。

## 決定事項（技術的方針）

| 項目 | 採用 | 理由 |
|---|---|---|
| **スタック** | React + Vite + TypeScript | 設定項目が多く状態管理が重い。`mixer` / `make-medley` と同構成で揃える。 |
| **配置** | `/sensitive-font/` 直下 | 単機能アプリなのでサブディレクトリを切らずここに置く。 |
| **描画** | Canvas 2D に自前レイアウト | SVG + `foreignObject` を画像化する方式は外部フォントが読み込まれず縦書きも破綻するため不採用。 |
| **フォント** | Google Fonts（OFL）+ ユーザーの手持ちフォント読込 | 日本語フォントは全部入りだと 3〜8MB/種。Google Fonts CSS は `unicode-range` で分割配信されるので実使用文字ぶんだけ数十 KB で済む。同梱できない商用フォントは `FontFace` API での読込で補う。 |
| **導線** | トップページに注意書き付きカードを追加 | 見つけられる状態にしつつ、成人向け用途であることを明示する。 |
| **インデックス** | `<meta name="robots" content="noindex,nofollow">` | GitHub Pages の project page なので `robots.txt` をドメイン直下に置けない。meta で対応する。 |

## アーキテクチャの肝

- **描画パイプライン**: `テキスト → 文字送りレイアウト計算 → Canvas へ装飾つき描画 → アルファ境界でトリム → PNG`
  の一方向。プレビューと書き出しは**同じ関数**を倍率違いで呼ぶ（見た目と出力を絶対にズラさない）。
- **フォントのロード待ち**: Canvas は「未ロードのフォントは黙って代替フォントで描く」ため、
  描画前に必ず `document.fonts.load(spec, text)` を待つ。`unicode-range` 分割配信では
  **使う文字を渡さないと必要なサブセットが落ちてこない**のがハマりどころ。
- **多重縁取り**: `strokeText` は中心揃えで太さが内外に半分ずつ乗るため、
  「外側から太い順に描いて最後に塗り」を重ねることで N 本の縁取りを表現する。
- **縦書き**: Canvas に縦書き機能はないので 1 文字ずつ配置する。
  `ー` `〜` `（）` `【】` は 90° 回転、小書きかな（`っゃゅょぁ…`）と `、。` は
  字面の右上／右下へオフセット、というテーブルを持つ。
- **濁点合成**: `イ゛グ゛ッ` のような表現のため、結合文字 U+3099 / U+309A を任意の文字に付与する。
  フォントによっては合成位置が崩れるので、崩れる場合は手動でオフセットできる逃げ道を用意する。
- **トリム**: `getImageData` のアルファ値を走査して上下左右の余白を検出し、任意パディングを残して切り出す。
  影やゆらぎで想定外にはみ出すため、描画キャンバスは十分に大きく取ってからトリムする。

## 実装フェーズ

### Phase 0 — 足場づくり
- `/sensitive-font/` に Vite + React + TS をセットアップ（`base: '/my-webpage/sensitive-font/'`）。
- `deploy-pages.yml` にビルド工程と `_site/sensitive-font/` へのコピーを追加。
- 年齢確認モーダル（sessionStorage）と noindex meta。
- トップページ `index.html` に注意書き付きカードを追加。

### Phase 1 — MVP: 横書き描画 + フォント選択 + ダウンロード
- 複数行テキスト入力、フォントサイズ、単色塗り。
- フォント一覧（OFL 十数種）から選択、ロード待ちを挟んで描画。
- 市松模様の背景でプレビュー、透過 PNG ダウンロード。

### Phase 2 — 装飾
- 多重縁取り（本数・色・太さを個別指定）。
- グラデーション塗り（縦2色 / 3色）、ドロップシャドウ、ずらしベタ影。
- 余白の自動トリム + パディング指定。
- プレビュー背景の切替（市松 / 白 / 黒 / 任意画像を読み込んで重ね確認）。

### Phase 3 — 文字組み
- 字間・行間・行揃え。
- **縦書き**（回転テーブル・小書きかな・句読点の位置補正）。
- 全体の傾き（シアー / 回転）、アーチ配置。
- 文字ごとのゆらぎ（サイズ・回転・上下オフセットをランダム or サイン波、シード固定可）。
- 濁点合成ボタン。

### Phase 4 — 使い勝手
- **手持ちフォント読込**（.ttf / .otf をドロップ → `FontFace` API で登録、そのセッション内で使用）。
- スタイルプリセット（白フチ極太 / 明朝二重縁 / ポップ体グラデ など）と文字列プリセット。
- 出力倍率（等倍 / 2x / 4x）、クリップボードへコピー。
- 設定の localStorage 保存と URL ハッシュ共有。

### Phase 5 — 仕上げ
- README、フォントのライセンス表記（OFL）。
- スマホでの操作性（パネルの折り畳み、タッチ操作）。


## 想定される限界

- Google Fonts 由来のフォントは**閲覧時に外部リクエストが発生する**（テキスト自体は送信されない）。
  完全にオフラインで使いたい場合は手持ちフォント読込を使う。
- 手持ちフォントで作った画像の配布可否は、そのフォントのライセンス次第。アプリ側では判断しない。
- 濁点合成や小書きかなの位置は**フォント依存**で崩れることがある。手動オフセットで逃がす。
- 巨大な文字数 × 4x 出力ではキャンバスの最大サイズ制限（ブラウザ依存、概ね 16384px 前後）に当たる。
  上限を超える設定は UI 側で止める。
