# 📸 Shot Bank

ゲーム（学マス想定）のスクリーンショットを**端末内に貯め込み**、あとから取り出すための Web アプリ。
最終的には「セリフ・表情・キャラの3軸で絞り込んで、選んだ候補をそのまま LINE に送る」ところまで作る。
設計の全体像は [`docs/shot-bank-plan.md`](../docs/shot-bank-plan.md) を参照。

## いまできること（Phase 0）

- **取り込み** — ファイル選択・ドラッグ＆ドロップ・貼り付け（複数枚まとめて可）
- **JPEG への再エンコード**（既定 ON）— 実測で **31.9MB → 3.0MB**（10 枚、1 枚あたり約 300KB）。
  原本のまま残す設定もある
- **重複の検出** — dHash（16×8＝128bit）で、同じスクショの二度取りを弾く
- **一覧と詳細** — サムネは画面に入ってから読む。詳細で原寸表示・削除
- **ZIP バックアップ／復元** — 画像・サムネ・目録を 1 ファイルに。復元時、既にある ID は上書きしない
- **PWA** — ホーム画面に追加でき、オフラインでも起動する
- **保存領域の表示**と永続化の要求
- **文字の読み取りと検索** — セリフ・話者・話数で絞り込み、当たった箇所を抜粋で示す。
  読み取り結果は手で直せる（直したものは以後の一括読み取りで上書きしない）
- **名簿とタグ** — 話者名から名簿が自動で育ち、誤読は編集距離で寄る。
  表情・写っている人・自由タグ・お気に入りで絞り込め、専用画面で次々タグを振れる

## 文字の読み取り（Phase 1）

取り込むとそのまま読み取りまで走る（設定で切れる）。tesseract.js（jpn+eng）を使い、
資材は `public/vendor` から自前配信する（`scripts/copy-assets.mjs`）。

**画面は「ヘッダ / 本文パネル / 操作バー」の組み合わせ**でできていて、それぞれ独立に出たり出なかったりする。
パネルの有無だけで分岐すると、ヘッダと操作バーはあるのにパネルだけ無い「セリフのない間」の画面で、
読めるはずの話数を落とす。

**パネルは明るさでは見つからない。** 白い服や明るい背景が全幅で明るく出るため。
分かれ目は **左右の余白（本文が絶対に来ない帯）まで平坦かどうか**。UI の面はそこも無地で、絵はざらつく。

**話者名チップは大きさの決まった UI 部品**だった（実測で幅は画像幅の 38.6%、
名前の長さにも端末にも依らない）。動くのは縦の位置だけなので、そこだけ測る。

**二値化は領域ごとに変える。** 文字の出方が 3 通りあるため。本文は明るい地に暗い字、
話者チップは白字と黒字の両方、ヘッダは半透明の暗いチップに白字、横の字幕は縁取りの白字。

**読めなかったものは残さない。** もっともらしい字の割合で足切りし、捨てて空にする。
崩れた文字列を保存すると検索の邪魔にしかならない。

実測 10 枚での結果: レイアウト判定 **10/10**、話者名 **5/5**、本文は 5 枚中 4 枚がほぼ完全、
話数は 6 枚中 5 枚。**横向きの字幕は読めない**ので、手入力で直す前提。

## 名簿とタグ（Phase 2）

**名簿はハードコードしない。** 読み取れた話者名がそのまま候補になり、既存に近ければ寄せ、
遠ければ新しい人として仮登録される。ゲーム側にキャラが増えてもアプリを直さずに追随できる。

**寄せ方は編集距離。** 名前の長さで許す食い違いを変える —— 2 文字までは完全一致だけ
（「清夏」と「千奈」は別人）、3〜5 文字なら 1 字、6 文字以上なら 2 字まで。
Phase 1 で「香名江」が「理名江」と読まれて検索に当たらなかった件は、これで拾える。

**話者チップの色が裏取りになる。** 実測で色はキャラ固有だった（清夏 `#92de5a`、
ことね `#f7d81e`、撫子 `#545365`、プロデューサーとサブキャラは無彩色 `#978d83`）。
字が 1 字違いでも色が大きく食い違えば別人とみなす。

**誤読を直すと、元の綴りが別名として残る。** 次からは編集距離に頼らず当たる。

**タグ付けは専用画面で。** 一覧から 1 枚ずつ開いて閉じてを繰り返すと数十枚で心が折れる。
1 枚を大きく出し、タップで振って、スワイプ（またはキー）で次へ送る。
画像の高さは決め打ちにしてある —— 読み込みで伸び縮みすると、タップしようとしたタグが動く。

## いちばん大事なところ

iOS Safari は「スクリプトから書ける保存領域」を **7 日間サイトを訪れないと消す**。
**ホーム画面に追加した Web アプリはこの対象外**になる。
なので初回に追加を促し、バックアップを取っていなければ警告を出す。
バンクとして成立させる生命線なので、Phase 0 の時点で入れてある。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/）
npm test         # vitest（実スクショ 10 枚での回帰を含む）
```

`src/lib/__fixtures__/` に実機のスクショ 10 枚を置いてある。
検出のしきい値はこの 10 枚を測って決めたので、境目そのものを回帰テストで固定している。
DOM に依存しない純関数（`layout` / `binarize` / `search` / `story` / `plausible` / `matching`）だけを
テスト対象にしているので、ブラウザなしで回る。

GitHub Pages には `/my-webpage/shot-bank/` 配下としてデプロイされる
（`.github/workflows/deploy-pages.yml` 参照）。

## プライバシー

画像もメタ情報もすべて端末のブラウザ内（IndexedDB）にのみ保存され、外部へは送信されない。
