# 📸 Shot Bank

ゲーム（学マス想定）のスクリーンショットを**端末内に貯め込み**、あとから取り出すための Web アプリ。
最終的には「セリフ・表情・キャラの3軸で絞り込んで、選んだ候補をそのまま LINE に送る」ところまで作る。
設計の全体像は [`docs/shot-bank-plan.md`](../docs/shot-bank-plan.md) を参照。

## いまできること（Phase 0）

- **取り込み** — ファイル選択・ドラッグ＆ドロップ・貼り付け（複数枚まとめて可）
- **JPEG への再エンコード**（既定 ON）— 実測で **31.9MB → 3.0MB**（10 枚、1 枚あたり約 300KB）。
  原本のまま残す設定もある
- **重複の検出** — dHash（16×8＝128bit）で、同じスクショの二度取りを弾く
- **一覧と詳細** — サムネは画面に入ってから読む。詳細で原寸表示・削除
- **ZIP バックアップ／復元** — 画像・サムネ・目録を 1 ファイルに。復元時、既にある ID は上書きしない
- **PWA** — ホーム画面に追加でき、オフラインでも起動する
- **保存領域の表示**と永続化の要求

## いちばん大事なところ

iOS Safari は「スクリプトから書ける保存領域」を **7 日間サイトを訪れないと消す**。
**ホーム画面に追加した Web アプリはこの対象外**になる。
なので初回に追加を促し、バックアップを取っていなければ警告を出す。
バンクとして成立させる生命線なので、Phase 0 の時点で入れてある。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド（dist/）
```

GitHub Pages には `/my-webpage/shot-bank/` 配下としてデプロイされる
（`.github/workflows/deploy-pages.yml` 参照）。

## プライバシー

画像もメタ情報もすべて端末のブラウザ内（IndexedDB）にのみ保存され、外部へは送信されない。
