# 🗯️ Comic Forge（コマ組み）

スクショを並べてコミック風の 1 枚に組み上げるツール。完全にブラウザの中だけで動き、
画像は端末から出ない。

<https://tsukuyomip.github.io/my-webpage/comic-forge/>

設計の全体像と、なぜその作りにしたかは [`docs/comic-forge-plan.md`](../docs/comic-forge-plan.md) にある。

## いまできること

| Phase | 中身 | 状態 |
|---|---|---|
| 0 | 骨組み・自動保存・作品ファイル（.zip）・PNG 出力 | ✅ |
| 1 | コマ割り（四辺形の木・分割・削除・入替・比率・溝・傾き・個別余白・枠線） | ✅ |
| 2 | 画像配置（取り込み・コマ内の移動／拡大／回転） | ✅ |
| 3 | 吹き出し | これから |
| 4 | 文字（縦書き・ルビ・同梱フォント） | これから |

## 作りの要点

- **レンダラはひとつ。** 編集画面も書き出しも `render(doc) → DrawOp[] → paint(ctx)` を通る。
  違うのは変換行列の倍率だけなので、「編集で見えていたものと違う絵が出る」が起きない。
- **コマ割りは四辺形を割る木。** 矩形ではなく四辺形で持つので、斜めの分割が
  まっすぐな分割と同じコードで出る。割を動かすと隣のコマの辺が必ず揃う。
- **描画命令を中間表現にした。** ブラウザなしで「何を描くか」を検証できる（`src/lib/__tests__`）。
- **溝は先に引いてから割る。** 全体を取り分で割ってから溝を食い込ませると、
  両端のコマだけ溝の半分ぶん大きくなる。CSS の grid gap と同じ考え方にしてある。

## 開発

```sh
npm install
npm run dev     # 開発サーバ
npm test        # 幾何・木・描画命令・作品ファイルの単体テスト
npm run build   # 型チェック＋ビルド
```

### 作品ファイルの版を上げるとき

1. `src/lib/defaults.ts` の `SCHEMA_VERSION` を 1 つ上げる
2. `src/lib/project-file.ts` の `MIGRATIONS` に v(N) → v(N+1) を 1 本足す
3. `node scripts/make-fixture.mjs <旧版>` で当時の zip を作り、
   `src/lib/__fixtures__/` に置く（**置いたら二度と書き換えない**）
4. `project-file.test.ts` に、その版が読めることを見るテストを足す

移行コードを書いただけでは下位互換は守れない。古い zip を実際に読ませて初めて守られる。
